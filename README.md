# 코스모 팡 · COSMO PANG

태양계 행성의 공전이 중력을 바꾸는 우주 블록 퍼즐 — 솔로운영 오락실.

**플레이:** https://craftburgers1.github.io/cosmo-pang/

- 조작: 블록을 옆 칸으로 밀거나 두 개를 차례로 탭해 자리를 바꿉니다(같은 행성 3개 이상 줄). 궤도를 도는 행성을 끌면 중력이 바뀝니다(중력 파도).
- 옮길 수 있는 수가 없으면 자동으로 섞입니다. 4개를 맞추면 혜성 블록(그 줄 제거), 5개 이상·ㄱ/ㅗ 모양이면 초신성 블록(같은 행성 전부 제거)이 생깁니다.
- 정식 모드: 하루 무료 10판(한국시간 자정 리셋), ☄ 혜성은 한 판에 최대 3번(첫 1회 무료, 이후 ✦15).
- 크레딧: 솔로운영 통합 지갑 `users/{uid}/wallet/main` — 가계부·근태 앱과 공용. 출석 보상·스테이지 클리어·가계부/근태 활동으로 쌓이고 한 판(✦10)·혜성(✦15)에 씁니다. 스펙은 `work/solo-credit-wallet-spec-v1.md`.
- 무중력 타임(ZERO-G): 스테이지 시작 12초 뒤부터 초당 2% 확률(블록 12개 이상) 또는 8콤보에서 7초간 발동. 그동안은 인접 제한 없이 블록을 아무 칸으로나 옮길 수 있습니다(블랙홀 칸 제외, 매치가 아니어도 그대로). 스테이지당 1번·한 판 최대 4번.
- 클랜: 국가(17개국)·지역(한국 17개 시도)을 골라 같은 지역 클랜에 만들거나 가입합니다. 한 사람 1개, 정원 30명, 탈퇴는 가입 글 삭제.
- 크레딧 선물: 같은 클랜원에게 하루 5회, 1회 ✦3(하루 최대 ✦15). 보내는 사람 지갑에서 차감되고, 받는 사람이 접속하면 한 번만 적립됩니다(하루 받기 10건까지, 14일 보관).
- 랭킹: 홈 `랭킹` 시트에 내 기록 · 개인 랭킹(전체 최고점 TOP 10) · 클랜 랭킹(클랜원 최고점 합, 전체/내 국가/내 지역 필터). 최고 기록이 갱신되면 올리기 카드가 뜨고, 예전 내 글은 지웁니다.
- 클랜·랭킹·선물 저장 위치: Firestore 규칙이 `users/{uid}/**`와 `community_board`만 허용하므로 공용 게시판에 `ARCADE|cosmo|...` 글(7키 고정, 수정 불가)로 저장합니다. 가계부 자유 게시판은 `ARCADE|` 글을 숨기고, 진상손님 랭킹은 `ARCADE|jinsang|`만 읽어 서로 섞이지 않습니다. 길게 보면 전용 컬렉션 + 규칙 게시가 필요합니다.
- Google 로그인: Firebase Auth(`alluser-77808`) — 최고 기록과 지갑이 계정에 저장됩니다.
- 파일: `index.html`, `style.css`, `game.js`, `cloud.js`, `firebase-config.js`, `assets/`
