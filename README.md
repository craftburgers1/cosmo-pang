# 코스모 팡 · COSMO PANG

태양계 행성의 공전이 중력을 바꾸는 우주 블록 퍼즐 — 솔로운영 오락실.

**플레이:** https://craftburgers1.github.io/cosmo-pang/

- 조작: 블록을 옆 칸으로 밀거나 두 개를 차례로 탭해 자리를 바꿉니다(같은 행성 3개 이상 줄). 궤도를 도는 행성을 끌면 중력이 바뀝니다(중력 파도).
- 옮길 수 있는 수가 없으면 자동으로 섞입니다. 4개를 맞추면 혜성 블록(그 줄 제거), 5개 이상·ㄱ/ㅗ 모양이면 초신성 블록(같은 행성 전부 제거)이 생깁니다.
- 정식 모드: 하루 무료 10판(한국시간 자정 리셋), ☄ 혜성은 한 판에 최대 3번(첫 1회 무료, 이후 ✦15).
- 크레딧: 솔로운영 통합 지갑 `users/{uid}/wallet/main` — 가계부·근태 앱과 공용. 출석 보상·스테이지 클리어·가계부/근태 활동으로 쌓이고 한 판(✦10)·혜성(✦15)에 씁니다. 스펙은 `work/solo-credit-wallet-spec-v1.md`.
- Google 로그인: Firebase Auth(`alluser-77808`) — 최고 기록과 지갑이 계정에 저장됩니다.
- 파일: `index.html`, `style.css`, `game.js`, `cloud.js`, `firebase-config.js`, `assets/`
